# Visual design credits

The pale, emaciated Scyer design is inspired by **SCP-096**, by **Dr Dan**, from the SCP Wiki:
https://scp-wiki.wikidot.com/scp-096

SCP-096 is licensed under Creative Commons Attribution-ShareAlike 3.0:
https://creativecommons.org/licenses/by-sa/3.0/

The original Scyer geometry, generated texture, and visual animation implementation in `ScyerModel.java`, `tools/generate_scyer_model.py`, `tools/scyer_geometry.json`, and `scyer_pale.png` are provided under that same CC BY-SA 3.0 license. No third-party models or textures are bundled. Other project code retains its existing license.

Research also consulted the public SCP-096 game implementation and credits at:
https://github.com/Guthen/guthscp096

The creature remains Scyer. Version 1.6 uses relentless proximity tracking rather than SCP-096's canonical face-view trigger. Armor, weapon sprites, equipment textures and miniature weapon geometry are original artwork; Adamantium and Uru refer to fictional Marvel metals. The additional visual assets and tools/generate_gear_assets.py are also supplied under CC BY-SA 3.0.
